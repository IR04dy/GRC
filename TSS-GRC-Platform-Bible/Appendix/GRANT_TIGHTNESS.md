## What the first run found

This file is regenerated from live state, so a repaired finding disappears from it. The
first run, 2026-07-26 on the dev tenant, found **one** section-A2 instance:
`REPORTING:WRITE` guarding `ReportScheduleController#create`, `#update` and `#runNow`
while held by zero of 57 roles — the entire write surface of scheduled reporting, 403 for
every persona, invisible because `PLATFORM_ADMIN`'s code bypass masks it and fail-closed
logs nothing. Repaired by **V321** (ORG_ADMIN + GRC_ADMINISTRATOR). Making those three
endpoints reachable then exposed a second defect behind them: `ReportScheduleService`
copied `name` and `description` but not `nameAr`/`descriptionAr`, so the API silently
dropped both Arabic columns. Nobody could have hit it — no request had ever completed.

Tightening these grants is **F2-13b**, not this script: each change needs a per-tenant
impact query first, because the same mistake has been made twice in the other
direction — F2-27's plan pre-committed to an AND-chain that would have 403'd 8 of 18
legitimate holders, and the grant table is what falsified it.
