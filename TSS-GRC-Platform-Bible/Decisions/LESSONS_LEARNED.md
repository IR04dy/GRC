# Lessons Learned

1. Feature breadth can hide weak end-to-end control integrity.
2. A permission annotation is not proof that the correct permission is used.
3. Actor names from request bodies are not identity.
4. A quorum calculation is meaningless if membership and attendance are caller-authored.
5. Schema separation without repository ownership is cosmetic modularity.
6. A licensing table without universal backend enforcement is packaging theatre.
7. Green unit tests can coexist with completely untested governance engines.
8. A route or screen is not a user journey.
9. Arabic labels do not prove Arabic task usability.
10. A document marked complete must be downgraded when executable evidence disagrees.
11. Shared controls create market value only when evidence scope and freshness remain visible.
12. Event-driven architecture begins with stable facts and ownership, not with buying a broker.
13. Microservices do not create bounded contexts; they amplify whatever boundaries already exist.
14. A Saudi advantage requires an operating process for regulatory updates, not hard-coded framework names.
15. The strongest sales demonstration is a traceable decision, not a dashboard count.
