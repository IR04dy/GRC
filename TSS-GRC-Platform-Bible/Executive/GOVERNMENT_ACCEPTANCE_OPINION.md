# Government Acceptance Committee Opinion

## Current recommendation

**Conditional rejection for final acceptance; eligible for controlled pilot after P0 closure.**

The reason is not missing functional scope. It is insufficient retained evidence for control effectiveness, accessibility, operational resilience and commercial isolation.

## Acceptance gates

| Gate | Current opinion | Required evidence |
|---|---|---|
| Functional scope | Conditional pass | Signed Arabic/English process catalogue and UAT |
| Authentication and authorization | Fail | Negative permission matrix, MFA/SSO evidence, forged-actor tests |
| Tenant isolation | Conditional fail | Automated two-tenant API, export, search, scheduler and websocket suite |
| Decision integrity | Fail | Authenticated actor IDs, four-eyes proof, membership-derived quorum |
| Arabic usability | Conditional fail | Saudi persona sessions; RTL and terminology defects closed |
| Accessibility | Not assessed | Independent WCAG 2.2 AA audit and assistive-technology tests |
| PDPL | Conditional | RoPA, rights, retention, breach, transfer and processor evidence |
| NCA security | Conditional | ECC applicability, control implementation statement and evidence |
| SAMA workloads | Conditional | outsourcing/cloud approval, residency and operational-resilience evidence |
| Performance | Not assessed | agreed workload model and production-like results |
| Backup and DR | Not assessed | witnessed restore, RPO/RTO and failover exercise |
| Deployment and rollback | Conditional | signed rehearsal with immutable artifact identifiers |
| Documentation | Conditional | Bible traceability and release evidence pack |

## Pilot conditions

- synthetic or approved masked data only;
- named sponsor and risk owner;
- restricted modules and users;
- no automated regulator filing;
- no legal or regulatory conclusion generated by AI;
- daily backup and tested recovery;
- formal incident path;
- exit and data-return plan.

## Final acceptance rule

Acceptance is based on observed evidence, not demonstration narrative. Every critical journey must be executed by the intended persona, with a second principal where required, in Arabic and English, while audit events and tenant isolation are observed.
